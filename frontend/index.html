Touchless Computer Control — Project Evaluation Dossier

1. Project Abstract & Objective

This project introduces a high-responsiveness, vision-guided desktop interaction framework that eliminates reliance on mechanical peripherals (mouse and keyboard). Leveraging standard commodity webcams, the system extracts 21 anatomical 3D hand landmarks in real time and transforms hand kinematics into operating system input events.

2. Mathematical Formulations & Innovations

Adaptive One-Euro Filter: Solves the classic jitter vs. lag trade-off by dynamically modulating cutoff frequency based on input velocity: fc = fc,min + β · |velocity|.

Dual-Threshold Hysteresis: Eliminates click bouncing at gesture boundaries by establishing an activation threshold (0.055) and release threshold (0.080) with a 0.025 dead-zone.

Kinematic Velocity Tracking: Evaluates horizontal wrist transit speed (|vx| > 0.40) to reliably recognize page swipes while distinguishing deliberate 0.85s open palm pauses.
